# GrowYourPresence

> AI-powered speaking event management template for discovering events, composing proposals, and tracking submissions with GitHub Copilot agents.

## What is this?

**GrowYourPresence** is a template repository for managing your speaking career with AI agents. It gives you a configurable system for discovering speaking opportunities, reviewing them in pull requests, composing tailored submissions, and tracking each session through its lifecycle with GitHub Actions and Markdown-based state.

## Getting Started / How to Use This Template

1. **Create your own repository**  
   Click **Use this template** on GitHub to create a new repository from this project, or fork it if that better fits your workflow.
2. **Configure your profile**  
   Edit the files in `config/` to add your speaker bio, target events, discovery criteria, and submission defaults.
3. **Run the label setup workflow**  
   In GitHub Actions, run the **sync-labels** workflow so the repository has the labels used by the agents and automation.
4. **Start discovering events**  
   Use the GitHub Copilot CLI **Event Discovery Agent** to begin finding relevant CFPs and opening review PRs in your repository.

## Configuration

- **`config/speaker-profile.md`** — Your bio, topics, expertise, credentials, and past sessions.
- **`config/discovery-criteria.md`** — The events you want to search for, preferred regions, event tiers, sources, and exclusions.
- **`config/submission-defaults.md`** — Your preferred session formats, topic mappings, proposal defaults, and bio variants.
- **`config/submission-agent-grounding.md`** — A living knowledge base of learnings from PR feedback and submission edits; this grows over time.

## Dashboard

The operational dashboard lives in **`DASHBOARD.md`**.

- It is auto-generated by `node scripts/generate-readme.js`
- It shows active events, submissions, and archived items
- It is updated automatically by workflows and agents
- **Never edit the dashboard tables manually**

## How It Works

GrowYourPresence uses **GitHub Copilot CLI custom agents** and **GitHub Actions** to move opportunities through a repeatable workflow:

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│  🔍 Discover  │────▶│  📋 Review   │────▶│  📝 Compose  │────▶│  ✏️ Refine   │────▶│  🚀 Submit   │
│  (CLI Agent)  │     │  (You + PR)  │     │  (CLI Agent) │     │  (You + PR)  │     │  (You + Issue)│
└──────────────┘     └──────────────┘     └──────────────┘     └──────────────┘     └──────────────┘
   On-demand           Merge = approve       On-demand           Merge = ready       Label lifecycle
```

- **Discover** — The discovery agent finds relevant CFPs and creates one PR per event.
- **Review** — You review the event PR, request changes, merge it, or reject it.
- **Compose** — The submission composer agent drafts tailored session proposals for approved events.
- **Refine** — You edit, comment on, and finalize proposals in PR review.
- **Submit** — You submit sessions externally and track outcomes in GitHub with labels and issues.

## State Machine

### Event Lifecycle
```
discovered → shortlisted → [PR merged] → approved → drafting → submitted → admitted 🎉
                                                              → submitted → rejected ❌ → archived
                         → [PR closed + rejected label] → archived
```

### Submission Lifecycle
```
draft → [PR merged] → ready → (pending-submission issue)
  → submitted → accepted ✅
  → submitted → rejected → archived 🗄️
```

### Event Statuses

| Status | Emoji | Meaning |
|--------|-------|---------|
| `discovered` | 🔍 | Found by agent, PR open for review |
| `shortlisted` | ⭐ | Tier 1 event, high priority review |
| `approved` | ✅ | PR merged — submissions being composed |
| `drafting` | 📝 | Submission proposals in progress |
| `submitted` | 📨 | Sessions submitted to CFP — awaiting decision |
| `admitted` | 🎉 | One or more sessions accepted |
| `rejected` | ❌ | Not interested — will be archived |
| `closed` | 🔒 | CFP expired |
| `archived` | 🗄️ | Archived by cleanup |

### Submission Statuses

| Status | Emoji | Meaning |
|--------|-------|---------|
| `draft` | 📝 | Initial proposal in PR |
| `ready` | 🚀 | PR merged — ready to submit |
| `submitted` | 📨 | Submitted to event CFP |
| `accepted` | 🎉 | Session accepted! |
| `rejected` | ❌ | Not selected |
| `archived` | 🗄️ | Archived by cleanup |
